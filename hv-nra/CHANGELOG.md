# CHANGELOG — HV NRA (volume-high detection ladder)

All versions are GENERATED by `build_hv_ladder.py` (one source of truth for the
repetitive per-tier blocks). Edit the generator, never the `.pine` by hand.

## v3 — 2026-06-29 — Magnitude layer + deep ladder

`versions/HV_NRA_magnitude_ladder_v3_2026-06-29.pine`

**Why:** v2's only output was the deepest nested lookback tier a bar reached
(50…1000). That label is a **recency** measure ("how long since volume was this
high?") and says nothing about **magnitude**. Consequences seen live: a
quiet-stretch dud gets stamped a "1000-high", and a genuinely huge bar wears a
small "400" sticker because one bigger bar sits 401–450 bars back. The label was
sorting signals on the wrong axis.

**What changed:**
- **Deep ladder.** Fine 50-step `50…1000` (20 tiers) + coarse `2000/3000/4000/4999`
  (4 tiers). Top tier is **4999, not 5000**, on purpose: `ta.highest(volume,N)[1]`
  references `N` bars back, and Pine's `max_bars_back` ceiling is 5000, so 4999
  keeps the deepest reference comfortably within the cap. `indicator(max_bars_back=5000)`
  is set explicitly. Tiers stay nested → exactly ONE tier marker per bar.
- **Magnitude-in-context layer:**
  - `pop = volume[1] / sma(volume, popBaseLen)` — "× the recent average". One short
    baseline (default 50) so it's comparable across tiers and immune to
    drought-inflation. **NOT** the suite's session-anchored `tv_ta.relativeVolume()` —
    a plain rolling ratio, deliberately named `pop`.
  - Per-tier **ring buffers** (`hist{N}`) keep the last *K* highs of each window.
    Depth grows as the window shrinks (4999→10, 4000→15, 3000→20, 2000→25,
    1000→30, smaller→more, up to 50→49). Each depth is an input; `memMult` scales
    them all.
  - `relVsPriorHighs = volume[1] / median(prior K N-highs)` — "this 1k vs prior 1ks".
  - **Record flags** `recRecent` (biggest N-high in memory) and `recEver` (per-tier
    all-time max). `recEver` for the top tier converges to HEV by definition;
    `recRecent` is the genuinely useful one.
  - `rank` of the high within its ring buffer (1 = biggest).
- **Markers colored by `pop`** by default (toggle `colByPop`) so impressive highs
  glow hot regardless of which window labeled them. An extreme-`pop` **star** and a
  per-tier-record **square** are added. (Pine `plotshape` size is const-only, so
  magnitude is encoded in color, not size.)
- **Alert metadata.** `alertcondition()` messages are const-only, so the rich
  metadata is emitted via the **`alert()` function** (dynamic string: tier, vol,
  pop, relVsPriorHighs, rank, record flags, hotspot). Legacy per-tier
  `alertcondition()`s are kept for backward compat and carry `pop`/`rel` through
  `{{plot("...")}}` placeholders (hidden `plot()`s named `pop`/`relPrior`/`tier`).
- **Exports** grew: `signalStates[26]` (24 tiers + HEV + HotSpot), `activeVolSignals`
  (0..25), plus `dispN/dispTier/dispRel/dispRank/dispRecR/dispRecE` and per-tier
  `rel{N}/rank{N}/recR{N}/recE{N}`.

Non-repainting architecture preserved verbatim: `volume[1]` + `…[1]` + `offset=-1`,
plot==alert via shared `plot_*` booleans.

## v2 — 2026-06-13 — Full 50-step ladder + Hot Spot
