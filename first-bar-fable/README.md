# First Bar Fable

**Current version:** `v1` → `versions/FIRST_BAR_FABLE_v1.pine`

Composite first-bar detection study, named in homage of Fable. 17 detection
plots (S1–S17) assembled from verbatim ports of the suite's canonical engines
(1st PUP FAUNA, B2B PUP v5.4, TNT OD v3, SQUARIFY v3, Heavy Weapons Singles v2).

- **First Bar Master** checkbox (default ON): detections only fire when their
  reference bar is the first bar of the session. Uncheck to fire on any bar.
- Every S plot has its own checkbox that gates **both** the plot and the alert.
- Pine v5, non-tick study. Fast Calculation must stay OFF in TradingView.

See `CHANGELOG.md` for the full plot table and the interpretation notes.
