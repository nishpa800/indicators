## 🧾 COVERAGE GUARANTEE
**Every indicator study in this repo is on this page.** Every one of the **95** non-vendor
`.pine` files appears in exactly one section below: each tick-friendly build is paired with
its original non-tick source, and every original that has **no** tick build yet is listed as
an explicit GAP — nothing is silently omitted. Enforced mechanically by
`tools/check_index_coverage.sh` (fails if any `.pine` file is missing from this page).
Excluded by design: `vendor/pine_libraries/` (TradingView's own built-in reference sources —
not our studies).

### Status legend
- ✅ **CONFIRMED** — loaded live, no error.
- 🟡 **FIXED IN CODE, NOT CONFIRMED** — known errors patched in source; awaiting your live load.
- ❌ **BROKEN / UNRESOLVED** — known error not yet fixed. Do **not** rely on it. (none right now)
- 🕳️ **GAP — NO TICK BUILD YET** — original exists, tick-friendly conversion not made yet. Time charts ONLY.
- ⛔ **BANNED / NOT LOADABLE** — do not load, ever.

### Hard rules
- **On a tick chart (…T interval):** load ONLY from Set A, Set B, or Set C below. **Never** load
  anything from an `Original` column, `imports/`, or `versions/` on a tick chart — originals
  carry the RE10023 blank-anchor bug and crash on bar 0.
- **On a time chart:** originals are the canonical parity lineage and are fine — except
  ULTRA v57's original, which additionally carries RE10140 (>64 plot objects) and RE10008;
  prefer the TF build even on time charts for that one.
- Hit an error? Paste me the trace. I'll flip that row to ❌, quarantine it, and not present it
  as working until it's actually fixed + you confirm.
